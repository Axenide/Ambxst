## 2. Broken External Dependencies

### 🔴 CRITICAL — `axctl` Dependency Not Rebranded

**Files:** Multiple QML files, shell scripts
**Problem:** NothingLess depends on the `axctl` binary (Ambxst's system daemon) for:
- `modules/services/AxctlService.qml` — runs `axctl daemon` and `axctl subscribe`
- `modules/services/CompositorConfig.qml` — uses `axctl config get-animations` and `axctl config raw-batch`
- `modules/services/CompositorKeybinds.qml` — uses `axctl config keybinds-batch`
- `modules/components/ContextMenu.qml:51` — `axctl system get-cursor-position`
- `config/KeybindActions.js` — `axctl monitor set-dpms 0 0` / `axctl monitor set-dpms 0 1`

**Problem:** If the user doesn't have `axctl` installed from Ambxst, these features silently fail.
**Fix:** Either:
1. Create a `nothingless` daemon that replaces `axctl` (recommended)
2. Make a compat wrapper that detects `axctl` availability and falls back gracefully
3. Document that `axctl` is a required dependency

### 🔴 CRITICAL — PresetsService ConfigDir Confusion

**File:** `modules/services/PresetsService.qml`
**Lines:** 19, 120-134
**Problem:** `Config.qml` defines configDir as `~/.config/nothingless/config`, but `PresetsService.qml` defines it as `~/.config/nothingless`. The comments are STILL talking about `Ambxst` paths and have hardcoded fallback logic. The hardcoded comment lines 120-132 show the developer was confused about the path mismatch.

**Fix:** Either:
1. Align PresetsService to use `configDir + "/config"` like Config.qml
2. Or change Config.qml to use `nothingless` as base dir
3. At minimum, resolve the path mismatch and clean up comments

## 8. Security Issues

### 🟡 MEDIUM — UpdateService Runs Shell Injection

**File:** `modules/services/UpdateService.qml:137`
**Code:** `notify-send -a 'Ambxst Update' -i system-software-update -w '" + summary + "' '" + body + "'`
**Problem:** The `summary` and `body` are constructed via string concatenation from version strings. If a malicious GitHub tag contains shell metacharacters, this could be exploited.
**Fix:** Use parameterized arguments to `Process` instead of `bash -c` concatenation

### 🟢 LOW — No Secret Scanning Config

**Fix:** Add `.gitattributes` and `.secretlint` or similar to prevent credential leaks

**File:** `shell.qml`
**Problem:** All modules (bar, notch, dock, desktop, lockscreen, overview, dashboard) are loaded eagerly at startup, even if the user has disabled them in config
